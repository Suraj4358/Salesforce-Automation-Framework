# 🤖 Salesforce Automation Testing Framework

## 📌 Project Overview

This project is a Selenium WebDriver based automation framework developed using Java, TestNG, Maven and Page Object Model (POM).

The framework is designed to automate Salesforce web application scenarios and support maintainable and reusable test automation.

---

## 🛠️ Technology Stack

| Technology | Usage |
|---|---|
| Java | Programming Language |
| Selenium WebDriver | Web Automation |
| TestNG | Test Execution & Assertions |
| Maven | Build & Dependency Management |
| Page Object Model | Framework Design |
| Git & GitHub | Version Control |
| Jenkins | CI/CD |
| Extent Reports | Test Reporting |

---

## 🧪 Testing Scope

- Salesforce UI Testing
- Functional Testing
- Smoke Testing
- Regression Testing
- Integration Testing
- End-to-End Testing
- Cross-Browser Testing
